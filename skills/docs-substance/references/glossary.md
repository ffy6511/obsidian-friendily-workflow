# 词表门禁

本 Skill 不自带某一产品的词表。家喻户晓且不是项目切口的词可以留。项目自造复合词不当普通中英文。

## 仓库里已经有

找到约束词表和检查脚本（常见在 `docs/glossary.md`、`scripts/check_*.py`）。改读者会读到的文案后跑一遍。失败先改用词，再继续。

## 用户要冻结用词

再为这个仓库建：

1. **词表** — 每条：规范写法、Avoid、适用表面（对外 / 贡献者）。不要把贡献者词写进对外表面。
2. **脚本** — 可从本 Skill 的 [scripts/check_banned_terms.py](../scripts/check_banned_terms.py) 拷进仓库，配一份 terms 文件和要扫的 glob。把 glob 收成读者会读到的文件，不要扫设计底稿。
3. **准出** — 改对外文案的 CI / 本地检查跑这个脚本。

词表权威在仓库里，不在本 Skill。
